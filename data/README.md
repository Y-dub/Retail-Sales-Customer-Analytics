# Data

Source: UCI "Online Retail" dataset (UK online giftware retailer, Dec 2010 – Dec 2011).
Download `online_retail.csv` from the public mirror, then run the analysis scripts:
https://raw.githubusercontent.com/databricks/Spark-The-Definitive-Guide/master/data/retail-data/all/online-retail-dataset.csv

(Raw and derived CSVs are git-ignored to keep the repo light — they regenerate from the script.)
