# Data

Source: [UCI Online Retail dataset](https://archive.ics.uci.edu/dataset/352/online+retail)
(UK online giftware retailer, Dec 2010 – Dec 2011), via a public mirror.

Download it with `python analysis/00_download_data.py`, then run the analysis scripts.
